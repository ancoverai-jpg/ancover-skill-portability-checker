Ancover Skill Preflight is an experimental local checker for maintainers sharing agent Skills. It reports a bounded set of metadata, resource and packaging findings with a digest of the inspected content. It runs offline after dependency installation and does not execute the target package. Runtime compatibility and safety remain separate checks.
