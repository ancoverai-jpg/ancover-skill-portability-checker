Alternatives/current gap:
- [MCP Inspector](https://modelcontextprotocol.io/docs/tools/inspector) is the reference live tool discovery/debug client. Prefer it for capture and live diagnosis. This Skill does not replace connection testing or schema validation.
- [RugSnare](https://github.com/Paraphern/rugsnare) already offers contract pinning/diff, proxies and deeper classifications. Its public metrics/security claims were not independently verified. Prefer an existing supported tool when it fits; no superiority or novelty claim here. Proposed narrow gap: two already-acquired private complete snapshots, standard-library-only offline comparison with value-suppressing reports, no server launch/config discovery, no security/breaking-change classification.
- [MCP fingerprint discussion#2744](https://github.com/modelcontextprotocol/modelcontextprotocol/issues/2744) was converted to a discussion, not an accepted universal fingerprint standard. This helper uses an explicit local typed representation, not JCS or an interoperable MCP fingerprint.
- Plain textual diff is useful for a private detailed investigation but includes raw definitions and can overemphasize key/tool ordering. This helper ignores object-key/tool-list order while retaining array order, exact strings, presence/null and number lexemes.
