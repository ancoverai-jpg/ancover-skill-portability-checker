# Ancover MCP Structured Result Check
Experimental offline review of one selected legacy MCP2025-06-18 tool result against its outputSchema. [Skill](../../skills/mcp-structured-result-check/SKILL.md) · [Specification](specification.md) · [Demand and alternatives](research.md) · [Português](README.pt-BR.md)

Install Python3.12+ in a short-path isolated virtual environment, then install the Skill requirements with pip --require-hashes --only-binary=:all:. Use that environment's Python to run the trusted helper against a private selected snapshot. See the Skill for exact commands and [synthetic sample](../../examples/mcp-structured-result.json). The sample should produce MATCH and exit0. Change count to a string to observe MISMATCH/exit1. No external services or API credentials are required.

Input format: profile=mcp-2025-06-18-draft202012; tool is the selected declaration with outputSchema; callResult is the selected result object, not JSON-RPC. Extra capture metadata may accompany these objects but is not verified. The helper compares only structuredContent; content is not parsed or treated as evidence of success. Missing outputSchema => NOT_APPLICABLE/2; tool isError=true => TOOL_ERROR/1.

Profile limits: strict UTF-8 JSON, duplicate keys, NaN and non-finite parsed numbers rejected, maximum1MiB,12000 value nodes, depth48, worker deadline5sec. Root schema must explicitly type object. Draft2020-12 only, defaulted if $schema absent. Nonlocal $ref/$dynamicRef and custom $vocabulary => INDETERMINATE, including conservative matches inside annotations/const. Local fragment references supported. No format assertions; unknown extension keywords follow jsonschema annotation behavior. No automatic defaults/coercion, URI fetching or filesystem reference lookup. Invalid schema, unavailable dependencies and unresolved recursion => unknown. Deadline is not an OS memory sandbox.

Reports suppress data, field names, schema fragments, local paths and exception messages, and include a SHA256 of the selected file. Digests can identify known inputs; a report is not an anonymization guarantee. The helper reads a bounded file, starts its own trusted worker and writes JSON to stdout; it does not mutate the snapshot, run the target tool or send telemetry. Dependencies are fetched only by explicit installation.

Limits of evidence: source/helper tests on synthetic captures do not prove an actual MCP server call or transport conformance. Codex isolated lifecycle/helper execution is tested separately from conversational trigger behavior (NOT_TESTED). Claude Code executable and conversational coverage remain NOT_TESTED. No cross-host stable claim. Review [validation](validation.md). Modern MCP2026-07-28 behavior is outside this pinned legacy profile.

Requirements pin official PyPI wheel hashes; no vendored dependency source. Retain installed package license notices when redistributing wheels. Existing SECURITY.md and CONTRIBUTING.md apply.

Update/uninstall: review the diff and requirements hashes, replace only this package/Skill installation, reinstall dependencies into a separate environment and rerun the synthetic example. Remove only the installation and dedicated virtual environment you created. Never remove a shared environment or personal host settings. Isolated Codex lifecycle testing exercises manual reinstall; automatic host updates remain NOT_TESTED.
