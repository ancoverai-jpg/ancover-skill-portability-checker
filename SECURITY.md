# Security

Version 0.1 is experimental. Review findings and source before use. The checker never executes target code, but is not a sandbox: inspect a stable snapshot in an isolated environment for hostile targets. Filename filters are not a secret scanner. The digest excludes Git, installed dependencies and runtime state; it is not signed. Reports may reveal local filenames. There is no telemetry.

Do not disclose secrets or exploitation details in public issues. GitHub private vulnerability reporting is enabled: use the repository's [Security advisories](https://github.com/ancoverai-jpg/ancover-skill-portability-checker/security/advisories) to report confidential vulnerabilities. No response SLA is claimed. For public, non-sensitive defects, provide a minimal synthetic fixture. Dependency graph and Dependabot alerts are enabled. Dependencies are pinned by pnpm-lock.yaml; install with scripts disabled and review dependency updates before merging. The YAML parser declares ISC licensing; see [third-party notices](THIRD_PARTY_NOTICES.md).

The optional MCP helper uses six separately pinned Python wheels (requirements.txt with SHA256 hashes); install only in an isolated environment. It never retrieves schema URIs, prints instance values or calls target tools. Selected file size/structure and a five-second worker deadline are bounded; this is not an OS memory sandbox. For hostile schemas use an OS sandbox. Do not share private snapshots. Snapshot hashes can reveal equality with known inputs. Format assertions are disabled and partial-profile matches do not certify MCP conformance. Dependency notices are in THIRD_PARTY_NOTICES.md.

MCP catalog comparator: selected bounded JSON only, no target process/network/approval changes. Duplicate keys/names and partial/mismatched-scope inputs fail closed. Number lexemes are retained without float rounding. Tool-name/file hashes and indices may identify known data; do not treat reports as anonymous. Equality is neither server authentication nor security/compatibility judgment. Use stable local files, not a concurrently hostile filesystem.
