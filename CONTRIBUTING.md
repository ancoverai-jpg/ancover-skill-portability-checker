# Contributing

Explain a reproducible problem and the rule or workflow it affects. Keep portability rules separate from host-specific observations. Add a regression fixture for behavioral changes, run `pnpm install --frozen-lockfile --ignore-scripts`, `node --test tests/*.test.mjs` and the checker on this repository. Report your OS, Node version, commands and unavailable host coverage. Do not submit credentials or proprietary packages. New heuristics need documented false positives and limitations. Keep the canonical Skills and all manifest versions consistent. Prefer focused PRs; no fabricated evidence or badges. Maintainers triage correctness and security before adding new products.

For Python helpers use Python3.12+ and an isolated environment. Install MCP dependencies with python -m pip install --require-hashes --only-binary=:all: -r skills/mcp-structured-result-check/requirements.txt, then run python -B -m unittest discover -s tests -p "*_test.py". Do not weaken missing/unknown/error distinctions, fetch schema URLs or log instance values. Use only synthetic non-sensitive regression captures. Dependency updates must review wheel provenance, licenses and hashes on both CI systems. Keep numeric/file/depth/deadline limits explicit.

Catalog-diff changes must preserve unknown declaration fields, number lexemes, duplicate/partial-input guards and value suppression. Use synthetic catalogs and test same-name schema changes plus reorder-only equality. The new helper is Python stdlib only; do not silently introduce capture, server launch, URL retrieval, baseline approval or semantic/security grading.
